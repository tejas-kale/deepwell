Menu rater

Load a pairs file

Choose runs/<run>/rater/pairs.json (or retest.json). Don't open the .key.json next to it: it says which model made which menu.

For each pair, ask: which menu would serve me better this week? Judge whether each bundle hangs together, whether the bundles are distinct and cover what the library is strongest on, the order from introductory to deeper, and whether the reasons are right. The app already enforced bundle lengths. Choose Tie only when neither is clearly better.

Keys: A B T to rate (moves on), ← → to move. Ratings are kept in this browser as you go; press Download ratings at the end and save the file in the same rater folder.
